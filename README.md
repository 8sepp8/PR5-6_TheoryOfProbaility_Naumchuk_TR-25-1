## Опис проєкту
Цей репозиторій містить програмну реалізацію практичної роботи, присвяченої застосуванню теорем додавання та множення ймовірностей, а також методу Монте-Карло для оцінки надійності складних ІТ-систем.

Робота розділена на 4 блоки:
* **Блок 1:** Симуляція умовної ймовірності та перевірка незалежності подій (запити до БД).
* **Блок 2 (Варіант 1):** Моделювання каскадної відмови незалежних маршрутизаторів.
* **Блок 3:** Оцінка надійності серійно-паралельної розподіленої веб-системи (LB, Web, DB).
* **Блок 4 (Варіант 4):** Перевірка системи резервування (Failover) у кластері баз даних.

## Структура репозиторію
* `src/` — вихідний код Python-скриптів для кожного з блоків.
* `graphics/` — графіки збіжності статистичних частот до теоретичних ймовірностей.
* `report/` — підсумковий звіт у форматі PDF із теоретичними розрахунками.

## Запуск та залежності
Для запуску потрібен Python 3.x та бібліотека `matplotlib` для побудови графіків.
